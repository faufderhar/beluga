**Beluga 3.6: Straight to main for small changes, every monospace font in the terminal, Codex from mise or asdf, and keys caught in more shapes.**

- **Straight to main**: a new worktree can land on main instead of its own branch. Pick **Then › Straight to main** in the new-worktree box and the agent still works in a worktree of its own, but when each turn ends Beluga commits, rebases and fast-forwards the main folder. No branch, no PR, nothing pushed, and your own uncommitted changes in the main folder are never touched. Any worktree with work and no PR can switch to it from its branch menu, and the phone gets the same steps.
- **Every monospace font**: Settings › Terminal › Font lists every monospace font installed on this computer, not just twelve names, and a font you install shows up without a restart.
- **Codex from mise or asdf**: Beluga finds a Codex installed through mise or asdf (and in Homebrew's folders and `~/.local/bin`), and starts the real Codex behind a mise shim.
- **Keys in more shapes**: pasting a custom API key that doesn't match a known pattern gets a softer offer to keep it as a key, and any word you pick can be kept as one.
- **Usage statistics, split in two**: the middle level is now called **Essential** and sends only which features you use and Beluga's own tool calls, with no agent sessions. Whole sessions go only at **On**. Your saved choice stays as it was.
- **Calmer Usage page**: a quieter pass hero, and titles as a plain list.
- **Fixes**: a long menu stays below the title bar and its rows line up; a project opened from Settings › Environment comes up above Settings; a key chip in the message box ends where its words end.

The phone app is 3.6.0 too, with Straight to main's steps and the Essential level, and it updates by itself.

The Android app (`Beluga-3.6.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached.
